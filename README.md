# openworker-spring
A simple AI agent worker written using Spring Boot, Spring AI and LangGraphForJ.

## how to start the app?
refer the starter scripts in `support/scripts` directory. We can use app with local AI model deployments like LMstudio, Ollama or using other public Model Providers like Google, Open AI, and Anthropic.

## how to interact with the app?
To interact with this app use the CLI
https://github.com/shriamrut/openworker-spring-cli

## want to dynamically inject custom tools?
Use https://github.com/shriamrut/openworker-test-mcp-server/ as an MCP server
